# Victoria Square Barbers

Concept landing for a barbershop in Belfast. Move the cursor around the dark hero to light up the bottle and the barber.

Live: https://sydorenkodev.co.uk/demo/barbershop/

Case study: https://sydorenkodev.co.uk/work/barbershop

![Victoria Square Barbers](docs/preview.webp)

Plain HTML, CSS and JS, no build step. To run it locally, serve the folder with any static server, for example `python -m http.server`.
